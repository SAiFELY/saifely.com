1. Service Description

SAiFELY provides crash detection software for Karoo bike computers. The service monitors sensor data during rides and sends automated emergency alerts to designated contacts when a crash is detected.

2. License

A paid license is required to use SAiFELY. Each license is valid for 12 months from the date of purchase and is tied to a single Karoo device serial number. Licenses are non-transferable.

3. Limitations

SAiFELY is a supplementary safety tool and is not a substitute for emergency services. The crash detection system uses sensor-based algorithms that may not detect all crash types. False positives and false negatives may occur. SAiFELY requires an active data connection to send alerts.

4. Payment

Payment is processed securely via Stripe. All prices are in USD or GBP. Refunds are available within 14 days of purchase if the service has not been activated on a device.

7. SMS Program Terms

Saifely's SMS program ("Saifely Emergency Alerts") delivers an initial one-time invitation to any phone number added as an emergency contact, and, only after the recipient confirms by replying YES or via the confirmation link, sends crash alerts and cancellation messages when a rider's device detects a possible crash. Message frequency is event-based and typically less than one per month per rider.

Recipients may opt out at any time by replying STOP, UNSUBSCRIBE, CANCEL, END, or QUIT to any Saifely SMS, or by using the opt-out link in the invitation. Replying HELP returns program details, as does /sms-consent/help. Standard message and data rates may apply from the recipient's carrier. Carriers are not liable for delayed or undelivered messages.
